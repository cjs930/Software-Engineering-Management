### 課程目標
軟體工程與管理涵蓋的主題很廣，包含軟體開發工程技術與專案管理構面下各主題。本課程主要授課內容會先從瞭解軟體開發的本質、困難與原則，及瞭解軟體工程專業領域之國際(ISO)與產業(IEEE)相關的標準後，進而介紹主要的軟體開發流程模式、計畫式導向與敏捷式軟體開發流程。計畫式導向體開發流程主要介紹軟體能力成熟度整合模型 (Capability Maturity Model Integration, CMMI)；敏捷式軟體開發流程主要介紹敏捷宣言、原則、實務作法，包含極限編程 (Extreme Programming, XP) 與 ScrumBan。本課程教學採用問題導向學習(PBL)、工作坊體驗學習、個案研討方式、分組專題報告，並輔以業師的專題演講，希望修課學長姐能學會建立有效率的軟體開發流程及管理作業程序，進而提升軟體開發流程效率及如期如質如本完成軟體系統的開發。
